# Hotel PMS — Frontend

React + TypeScript + Vite. See the [repo root README](../README.md) for the full quick-start
(backend setup, seeded demo logins, etc).

```bash
npm install
npm run dev      # http://localhost:5173, expects the API at VITE_API_BASE_URL (see .env.development)
npm run build    # type-check + production build
```
